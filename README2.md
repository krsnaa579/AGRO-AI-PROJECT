# 🌱 Agro AI - Plant Disease Detection System

Agro AI is an AI-powered web application that helps farmers and users detect plant diseases using image processing and Machine Learning.  
The system analyzes uploaded leaf images and predicts the disease along with treatment suggestions.

---

## 🚀 Features

- 📸 Upload plant leaf images
- 🤖 AI-based disease prediction
- 🌿 Supports multiple plant diseases
- 💊 Provides treatment suggestions
- 🌐 Simple and user-friendly interface
- ⚡ Fast prediction system

---

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- TensorFlow / Keras
- OpenCV
- NumPy
